# Multiplayer Tic-Tac-Toe 🎮

A real-time multiplayer Tic-Tac-Toe game with room codes. No logins or installs — just share a code and play!

## Features
- 🎲 Room-code based matchmaking
- ⚡ Real-time sync via WebSockets (Socket.IO)
- 📱 Works on phones and laptops
- 🏆 Score tracking & rematch support

## How to Play
1. Enter your name and click **Create Room**
2. Share the 4-letter room code with your opponent
3. They enter the code and click **Join Room**
4. Take turns placing X and O — first to 3 in a row wins!

## Tech Stack
- **Backend:** Node.js + Express + Socket.IO
- **Frontend:** Vanilla HTML/CSS/JS (single file)
- **Hosting:** Glitch (free)
